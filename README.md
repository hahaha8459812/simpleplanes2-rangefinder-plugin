# SimplePlanes 2 Rangefinder Plugin

[English](README.en.md)

用受油管零件做激光测距仪和感应器，输出的数值作为 Funky Trees 变量供载具上任意零件引用。

## 安装

### 安装 BepInEx

发布包不含 BepInEx，需要单独安装。已经装好 BepInEx 5 的话，跳到「安装本插件」。

本插件在 BepInEx 5.4.23.5（Mono x64）上测试过，请使用 [5.4.x 版本的 BepInEx](https://github.com/BepInEx/BepInEx/releases)。下载 [BepInEx_win_x64_5.4.23.5.zip](https://github.com/BepInEx/BepInEx/releases/download/v5.4.23.5/BepInEx_win_x64_5.4.23.5.zip)，解压到游戏根目录，也就是 `SimplePlanes 2.exe` 所在的目录：

```text
SimplePlanes 2\
├─ winhttp.dll
├─ doorstop_config.ini
├─ .doorstop_version
└─ BepInEx\
```

启动一次游戏再退出，`BepInEx\plugins\` 与 `BepInEx\config\` 会自动生成。

### 安装本插件

从 [发布页](https://github.com/hahaha8459812/simpleplanes2-rangefinder-plugin/releases/latest) 下载 `SimplePlanes2Rangefinder-Release.zip`，解压后把 `SimplePlanes2Rangefinder.dll` 放到 `BepInEx\plugins\` 下的任意子目录，推荐一个插件一个目录：

```text
SimplePlanes 2\
└─ BepInEx\
   └─ plugins\
      └─ SimplePlanes2Rangefinder\
         └─ SimplePlanes2Rangefinder.dll
```

安装时游戏必须关闭：运行时这个 DLL 被占用。配置文件在首次启动时生成：

```text
BepInEx\config\com.codex.simpleplanes2.rangefinder.cfg
```

## 测距仪

在建造器中选中受油管零件，在零件属性面板的**零件名**输入框中命名，以 `RF_` 开头：

```text
RF_left
```

零件类型必须是 `Refuel-Probe-1`（配置项 `PartTypeId` 可改）。只改零件名而类型不匹配时，零件会被跳过，日志里给出类型警告。

变量名是零件名中第一个 `.` 之前的部分（含前缀），两端的空格会被去掉。变量名只能由字母、数字、下划线组成，首字符不能是数字；不满足时零件被跳过并记警告。前缀匹配区分大小写。零件名不能只有前缀（如 `RF_` 或 `RF_.r5`），否则整个零件被跳过并记警告。

输出是探针到障碍物的距离，单位米。短距离下约 0.01 米；距离很大时受浮点精度限制，达不到这个精度。

### 参数

零件名可附加以 `.` 分隔的参数：

```text
RF_left.r5.m500.c1
```

| 参数 | 含义 | 取值范围 | 不写时 |
|---|---|---|---|
| `r<n>` | 每秒测量次数 | 0.1 – 120 | 每秒 10 次 |
| `m<n>` | 射线长度，单位米 | 1 – 1000000 | 100000 米 |
| `c<0\|1>` | 是否隐藏同载具碰撞箱 | 0 或 1 | 1，隐藏 |

参数名的字母大小写均可。`r` 与 `m` 超出取值范围时按最近的边界值处理，例如 `r500` 会按 120 处理；`c` 只接受 0 与 1，其他取值记警告后忽略，保持不写时的行为。参数可全部省略、部分省略、顺序不限；同种参数写多次时最后一个生效。空参数段与无法识别的参数记一条警告后忽略，不影响该测距仪其余部分。`t` 只对感应器有效，写在测距仪上会被忽略并记警告。

### 示例

| 零件名 | 效果 |
|---|---|
| `RF_left` | 每秒 10 次，射线 100000 米，隐藏同载具碰撞箱 |
| `RF_left.r2` | 每秒 2 次 |
| `RF_left.m1000` | 射线 1000 米 |
| `RF_left.c0` | 不隐藏同载具碰撞箱 |
| `RF_left.m500.r5` | 与 `RF_left.r5.m500` 等价，顺序不限 |
| `RF_left.r5.m500.c1` | 三个参数写全 |

### 输出值

| 情况 | 值 |
|---|---|
| 射线命中 | 距离，米 |
| 射线长度内没有东西 | 射线长度 |

"正好在射线长度边界命中"与"完全没有东西"取值相同，无法区分。

### 在表达式中引用

变量名是零件名里第一个 `.` 之前的部分：零件名 `RF_left.r5.m500` 的变量名是 `RF_left`。

在建造器里 Ctrl+点击任意零件的输入框（控制面、旋翼、活塞等），填入表达式即可使用。例如填进一个升降舵：

```text
clamp01(1 - RF_left / 500)
```

这个升降舵的偏转量变成：距离 0 米时满偏，500 米时归零，中间平滑过渡。

表达式里只写变量名，参数后缀不写。

### 射线方向

射线自零件的 transform 位置沿零件本地 +Y（`transform.up`）发出，也就是探针圆头的指向。零件在建造器中的朝向决定射线方向。探针装在会转动的零件上时，射线随其一同转动。

### 多个测距仪

每个探针使用不同的零件名即可，各自独立刷新、独立射线长度：

```text
RF_front
RF_left
RF_right
```

### 作用域

变量属于其所在载具。一架载具的探针只影响该载具的表达式，不影响其他载具。

## 感应器

在建造器中选中受油管零件，在零件属性面板的**零件名**输入框中命名，以 `SN_` 开头：

```text
SN_beam
```

零件类型必须是 `Refuel-Probe-1`（配置项 `PartTypeId` 可改）。只改零件名而类型不匹配时，零件会被跳过，日志里给出类型警告。

变量名是零件名中第一个 `.` 之前的部分（含前缀），两端的空格会被去掉。变量名只能由字母、数字、下划线组成，首字符不能是数字；不满足时零件被跳过并记警告。前缀匹配区分大小写。零件名不能只有前缀（如 `SN_` 或 `SN_.r5`），否则整个零件被跳过并记警告。

感应器输出通畅度，有两种输出方式：

| 方式 | 写法 | 射线内没有东西 | 射线内有东西 |
|---|---|---|---|
| 极值 | 默认 | 1 | 0 |
| 线性 | 加 `t2` | 1 | `距离 / 射线长度`，远处接近 1，近处降到 0 |

极值方式表示路径是否通畅，线性方式表示畅通程度。

### 参数

零件名可附加以 `.` 分隔的参数：

```text
SN_beam.t2.m50
```

| 参数 | 含义 | 取值范围 | 不写时 |
|---|---|---|---|
| `r<n>` | 每秒检测次数 | 0.1 – 120 | 每秒 10 次 |
| `m<n>` | 射线长度，单位米 | 1 – 1000000 | 100000 米 |
| `c<0\|1>` | 是否隐藏同载具碰撞箱 | 0 或 1 | 1，隐藏 |
| `t<1\|2>` | 输出方式 | 1 极值，2 线性 | 1 |

参数名的字母大小写均可。`r` 与 `m` 超出取值范围时按最近的边界值处理，例如 `r500` 会按 120 处理；`c` 只接受 0 与 1、`t` 只接受 1 与 2，其他取值记警告后忽略，保持不写时的行为。参数可全部省略、部分省略、顺序不限；同种参数写多次时最后一个生效。空参数段与无法识别的参数记一条警告后忽略，不影响该感应器其余部分。

### 示例

| 零件名 | 效果 |
|---|---|
| `SN_beam` | 极值输出，每秒 10 次，射线 100000 米 |
| `SN_beam.m20` | 20 米内有东西输出 0，没有输出 1 |
| `SN_beam.t2.m50` | 线性输出，50 米内远处接近 1、近处降到 0，没有输出 1 |
| `SN_beam.c0` | 不隐藏同载具碰撞箱 |
| `SN_beam.r2.m20` | 每秒 2 次，射线 20 米，极值输出 |

### 输出值

| 情况 | 极值 | 线性 |
|---|---|---|
| 射线内没有东西 | 1 | 1 |
| 射线内有东西 | 0 | 距离 / 射线长度 |

极值方式下只要射线内有东西就是 0，任意命中都能与没有东西区分开。线性方式下"正好在射线长度边界命中"与"完全没有东西"取值相同，无法区分。

### 在表达式中引用

变量名是零件名里第一个 `.` 之前的部分：零件名 `SN_beam.t2.m50` 的变量名是 `SN_beam`。

在建造器里 Ctrl+点击任意零件的输入框（控制面、旋翼、活塞等），填入表达式即可使用。极值方式可以直接当开关：

```text
SN_beam
```

线性方式是连续量，取反可以得到"越近越大"的告警：

```text
1 - SN_beam
```

表达式里只写变量名，参数后缀不写。

### 射线方向

射线自零件的 transform 位置沿零件本地 +Y（`transform.up`）发出，也就是探针圆头的指向。零件在建造器中的朝向决定射线方向。探针装在会转动的零件上时，射线随其一同转动。

### 多个感应器

每个探针使用不同的零件名即可，各自独立刷新、独立射线长度：

```text
SN_left
SN_right
SN_beam
```

### 作用域

变量属于其所在载具。一架载具的探针只影响该载具的表达式，不影响其他载具。

## 卸载

删除 `BepInEx\plugins\SimplePlanes2Rangefinder\` 目录。配置文件可一并删除。
